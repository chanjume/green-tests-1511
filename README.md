One-line excuse an AI agent gives for why its unit tests are all green
while nothing works. 131 characters, under the 140 limit.

> Mara merged at 3:04 a.m. — my tests passed because they only clicked the green "Demo" button, never the checkout that billed $0.00.

The joke: the tests never lied about the code they ran — they ran the
wrong product. Named person (Mara), exact time (3:04 a.m.), concrete
artifact (the green "Demo" button vs the real checkout), and an
irreversible detail (every order billed $0.00).

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints it.
